# Store

The in-game shop. Runs in two modes: **Browse** (buy something on a player's behalf) and **Manage** (stock the store). Players buy in game with `/shop` and `/buy`.

New to the store? [Setting Up the Store](../../guides/setting-up-the-store.mdx) walks through it start to finish.

## Browse mode

A card grid of store items. **Buy for Player** opens a dialog listing the items and commands in that entry and its price, and asks which online player it's for. The player's points are spent as if they'd bought it themselves.

## Manage mode

Three tables:

| Column | Notes |

### Command definitions (reusable command packages)

| Column | Notes |
|--------|-------|
| Command | Console command; `{entityId}`, `{playerId}` and `{playerName}` are filled in at purchase |
| Main Thread | |

## Actions

- **Create / Edit / Delete** any row in the three tables above.
- **Buy for Player** (browse mode). Spends the player's points, drops the items at their feet, and runs the commands. The player must be online.

## Notes

- Store items are composed by referencing **item definitions** and **command definitions**, so you define reusable pieces once and mix them into multiple store entries.
- Item search inside the Create/Edit dialogs uses autocomplete with item icons from the [Item Database](../content/item-database.mdx).
